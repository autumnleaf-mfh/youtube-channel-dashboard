# YouTube 频道增长雷达

追踪 12 个财经 YouTube 频道的公开更新与增长数据，并通过 GitHub Pages 提供静态看板。频道名称使用 API 返回的当前频道名，随采集同步。

## 看板内容

- 当前订阅数、频道总播放、公开视频数
- 24 小时与 7 日订阅/播放变化（从首次快照开始累计）
- 7/30/90 日更新数、平均更新间隔、停更天数
- 近 5 条视频平均播放、平均点赞与公开互动率
- 单频道订阅、频道总播放及单视频公开互动历史
- 最新视频表现、停更提醒与采集健康状态
- 公开 Data API 与频道主 OAuth/Analytics API 的能力边界
- 各频道数据明细图：跟随趋势区指标及 7D / 30D / 90D / ALL 时间窗口，支持柱状图与分频道时间折线切换，包含零更新频道
- 完整已采集公开视频滚动列表：7D / 30D / ALL 发布时间窗口（默认 ALL）、频道筛选和播放量升降序均使用按钮，保留缩略图和视频链接
- 内容趋势默认选择全部频道，显示总和折线并禁用对比；单选频道后可选择对比频道及独立对比指标
- 全部频道的播放/点赞/评论按窗口内视频的香港发布日期每日求和（数值为最近一次累计值，不是每日新增）；更新数按日求和。订阅总和仅使用各频道同一采集时点齐全的快照，不拼接异步快照或将缺失补零
- 订阅数量趋势来自频道历史快照（按采集时间）；播放、点赞、评论沿用视频发布时间与最近一次公开累计值，更新数量按香港日期统计

## 自动更新

GitHub Pages 从 `main` 分支根目录直接发布；本机计划任务每 30 分钟运行一次，RSS 发现新视频时额外即时刷新：

1. 从 Windows DPAPI 凭据读取 YouTube API Key；
2. 调用 YouTube Data API v3 并更新 `site/data.json`；频道订阅、总播放及最新上传每 30 分钟刷新，7 天内视频明细每 3 小时刷新，8–30 天视频每日刷新，30 天以上视频每周刷新；
3. 只把新的公开快照写入 GitHub 的 `data.json`，密钥不会进入仓库。

首次部署后，24 小时和 7 日变化需要分别积累足够时间才会显示；缺失历史不会被当作 0。

## 本地更新与构建

```powershell
$env:YOUTUBE_API_KEY = "your-api-key"
$env:DASHBOARD_DATA_PATH = "site/data.json"
python scripts/collect_youtube.py
python -m http.server 8787 --directory site
```

## 数据口径

- 公开订阅数由 YouTube 按三位有效数字取整，也可能被频道隐藏。
- 更新数量以完整已采集上传目录中的发布时间计算，按视频 ID 去重；7D/30D 为截至采集时间的滚动窗口，ALL 为已采集全目录。每周、新增频道时完整扫描，成功后移除已不在公开目录的视频，保留历史观测。API 频道公开视频总数可能与上传目录暂时不同。
- 视频列表使用每条视频最近一次采集的累计播放量，不是窗口内新增播放；缺失指标显示 —，升降序均排在末尾。视频继续沿用分层采集频率。
- 历史变化不是 YouTube 提供的历史字段，而是本仓库的分层快照差值；频道历史也会把 7 天以上数据压缩为每日、30 天以上压缩为每周。
- `(点赞 + 评论) / 播放` 仅为本站的公开互动率定义，不等于 YouTube Studio 指标。
- 视频时长只用于“短视频候选”提示，不能单靠时长准确判定 Shorts。
- 展示次数、点击率、观看时长、留存、独立观众、流量来源和收入等数据需要频道主 OAuth 授权与 YouTube Analytics API。
